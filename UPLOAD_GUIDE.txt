Upload guide for the GitHub repository

1. Replace the root-level README.md with the README.md in this package.
2. Add STATISTICAL_METHODS.md to the repository root.
3. Upload all files in the figures/ folder into your existing GitHub repository's figures/ directory.
4. Upload all files in the tables/ folder into the tables/ directory.
5. Upload synthetic_dlbcl_demo.csv into the data/ directory if you want the public data file to match the updated figures.
6. You can keep your notebooks/ and src/ folders unchanged.

Recommended commit message:
Update portfolio figures and README with final public-facing display set
